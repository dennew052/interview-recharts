# Interactive Line Chart

React + TypeScript application visualizing A/B test conversion rates.

## 📊 Tech Stack
- React + TypeScript
- Recharts (charts)
- CSS Modules
- gh-pages (deployment)

## ✨ Features
- Interactive conversion rate chart
- Variation selector
- Day / Week aggregation
- Responsive layout
- Tooltip on hover

## 🚀 Setup
```bash
npm install
npm run dev
```
